## Overview

Alphacoders is a large library for wallpapers, avatars, mobile backgrounds, and GIFs. This browser extension makes the supported **Free Download** flow start immediately instead of waiting through the local 5-second countdown.

## Supported Areas

`alphacoders.com` / `wall.alphacoders.com` / `avatars.alphacoders.com` / `mobile.alphacoders.com` / `gifs.alphacoders.com`

## Install

1. Download `alphacoders-instant-download-v1.0.0.zip` from the [latest release](https://github.com/voidksa/alphacoders-instant-download-extension/releases/tag/v1.0.0).
2. Extract the ZIP file.
3. Open `chrome://extensions` or `edge://extensions`.
4. Enable **Developer mode**, click **Load unpacked**, and choose the extracted folder.

## Use

Open any supported Alphacoders image page, enable **Instant Download** from the extension popup, then click **Free Download**.

## Note

This extension does not modify account privileges. It only skips the client-side wait timer when an existing free download URL is available.
